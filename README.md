# Predict-Online-Gaming-Behavior-
As a former Marketing Specialist at a gaming start-up, I built an end-to-end data analytics project to understand how player demographics, gameplay behavior, and game features influence player engagement and retention.

## Dataset and PostgreSQL

The player snapshot CSV is in `data/`. PostgreSQL scripts create a raw staging layer, normalized tables, and a joined analysis view.

See [Database setup and schema](docs/database.md) for Neon loading instructions, validation, and interpretation limits.
